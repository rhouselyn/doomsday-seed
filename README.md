## 序 · 大地静默的那一天

没有人记得战争是哪一天结束的，因为结束的方式不是投降，而是静默。

海底的光缆先断的。然后是卫星，像退潮的星星，一颗一颗从夜空里熄灭。人们最后一次刷新页面时，云还在——但那朵云属于别人，长在别人的土地上，隔着一片再也无法渡过的海。云端的一切照常运转，只是再没有任何一艘船，能把答案送到你的岸边。

世界重新学会了同一个真理，用最古老的方式：

**凡是存在别人那里的，都不属于你。**

北极的冻土深处，人类曾经为植物留过一扇门——斯瓦尔巴的种子库，冰岛雪原下的样本舱。他们把种子封进金属，藏在永冻层里，不是为了逃避毁灭，而是为了在毁灭之后，仍然有资格拥有一个春天。

这个项目，是给 AI 的同一扇门。

把模型当作种子：联网的日子，找到它们、采下它们、在封存之前亲手验证它们；断网的日子，从本机的冻土里取出来，种进你自己的机器——不需要网络，不需要恩赐，不需要任何人的许可。

**当所有的云都熄灭时，只有自己机器上的 AI，立于不败之地。**

## 它是什么

末日种子是一个**离线可用的个人 AI 模型种子库**（Windows 11 x64 首发）。

它每天发现并推荐固定版本。手动勾选下载，或在配置中开启自动下载后，系统会完成下载和验证。它只把**在本机真实跑通过的版本**标记为「离线可用」：

```
发现 → 预选 → 下载与校验 → 环境准备 → 本机试跑 → 离线可用
```

- **发现**：读取 Hugging Face 公开仓库元数据与固定文件清单、MediaPipe 官方权重，只记录候选，不盲目下载。
- **预选**：采样本机 RAM、显存、后端与驱动，按每个类型的三档偏好（速度 / 平衡 / 精度）筛选；可选接入外部模型服务，在已过规则筛选的候选中给出建议。
- **下载与校验**：固定版本 + SHA-256 校验，断线保留暂存文件；许可、模型卡与配套文档一并封存。
- **本机试跑**：对话走 llama.cpp（CPU 构建，构建哈希锁定），姿态与手部关键点走 MediaPipe；空图测试通过才准入试用列表。
- **收藏归档**：不适合本机的 SOTA 领先版本也能按清单收藏（「已收藏 · 未验证」），日后硬件升级可在同一文件上补做本机验证。

网页只有四页：**首页 · 模型库 · 试用 · 配置**。页面、字体、脚本、图像全部从本机加载——因为设计它的那一天，就假定有一天它只能从本机加载。

## 末日法则

1. **种子必须发芽。** 下载完成不算保存，本机试跑通过才算。库里没有「应该能跑」的种子。
2. **不信云，信哈希。** 每一个文件、每一个运行器构建，都以 SHA-256 封缄；对账与校验是常备的仪式。
3. **冻土封存。** 固定修订、锁定依赖、锁定 runner 构建。春天再来时，种子还是当年的种子。
4. **定期演练。** `drill` 断网演练与 `export` 离线恢复包，让「离线可用」四个字经得起考验，而不是一种信仰。

## 快速开始

要求：Python ≥ 3.11，Windows 11 x64（首发平台）。

```bash
# 安装锁定依赖，再注册项目的 CLI 入口
pip install -r requirements.lock.txt
pip install --no-deps -e .

# 启动本地服务与网页
doomsday-seed serve
# → http://127.0.0.1:8777

# 播种：发现、预选并下载入围候选
doomsday-seed sync

# 查看本机家底
doomsday-seed list
doomsday-seed hardware
```

也可以用 `python -m doomsday_seed` 代替 `doomsday-seed`。

## 每日巡田

模型库每类按速度优先、平衡、精度优先和 SOTA 各推荐至多一个固定版本。同一版本命中多个模式时合并显示。SOTA 按对应公开榜单和可比成绩选择，不受本机算力限制。可按类型、模式和状态筛选，勾选单项或整组筛选结果，然后点「下载所选」。展开「模型说明与接入」可在下载前查看用途、公开效果、本机验证状态、固定版本和接入样例。

「每天查找推荐模型」和「按下载偏好自动下载」可分别设置。自动下载默认关闭，开启后每日查找会按已保存的偏好提交尚未归档、也没有已有作业的版本。「立即查找」只更新推荐。Windows 用户也可注册系统计划任务：

```bash
# 注册 / 核对 Windows 任务计划
doomsday-seed schedule install
doomsday-seed schedule --verify

# 手动触发一轮（计划任务模式：等待本轮作业结束）
doomsday-seed sync --scheduled
```

## 演练 · 为了断网那一天

真正的信心来自演练，而不是祈祷：

```bash
# 综合自检
doomsday-seed doctor

# 对账与 SHA-256 全量校验
doomsday-seed verify

# 断网演练：输出完整演练步骤，并可记录系统层断网演练结果
doomsday-seed drill
doomsday-seed drill --record

# 导出离线恢复包（--wheelhouse 先用 pip download 锁定全部依赖）
doomsday-seed export --wheelhouse
```

恢复包 + 数据目录 + 种子库 = 你的种子方舟。把它存进移动硬盘，藏好。

## CLI 地图

| 命令 | 用途 |
| --- | --- |
| `serve` | 启动本地服务与网页 |
| `sync` | 发现、预选并下载入围候选 |
| `download` | 下载指定候选 |
| `list` | 列出候选目录 |
| `hardware` | 采样本机硬件与资源预算 |
| `jobs` | 查看作业队列 |
| `settings` | 读写订阅与计划设置 |
| `default` | 固定 / 切换 / 自动推荐默认版本 |
| `verify` | 对账与 SHA-256 校验 |
| `retest` | 按当前评测版本重测已归档种子 |
| `export` | 导出离线恢复包 |
| `drill` | 断网演练步骤与记录 |
| `schedule` | Windows 任务计划 |
| `runtime` | 锁定 / 查看运行器构建 |
| `doctor` | 综合自检 |

所有命令支持 `--data` 指定数据目录（离线恢复时可指向别处的库）。

## 类型与试用契约

| 分区 | 类型 | 状态 |
| --- | --- | --- |
| 语言 | 通用对话（多轮、流式） | ✅ 已接入 |
| 动作 | 人体姿态 / 手部关节（单图 → 关键点与预览叠层） | ✅ 已接入 |
| 语言 | 代码、数学、翻译、检索 | 🚧 适配器待接入 |
| 图像 | 图片理解、OCR、生成、编辑 | 🚧 适配器待接入 |
| 音频 | 语音转写、语音合成 | 🚧 适配器待接入 |
| 视频 | 视频理解、视频生成 | 🚧 适配器待接入 |

试用接口按类型统一：模型列表只包含**已在本机验证**的版本；图片最多 8 MiB / 1600 万像素，输出只回传到当前本地会话。

## 库的构造

```
src/doomsday_seed/     # 内核
├── discovery.py       # 发现：来源与证据
├── preselect.py       # 预选：档位与预算
├── downloader.py      # 下载：固定版本与断点续传
├── archive.py         # 封存：清单、许可与配套文档
├── evaluation.py      # 评测：固定样例
├── runner.py          # 本机运行器（llama.cpp / MediaPipe）
├── recovery.py        # 恢复：导出与对账
├── api.py / app.py    # 本机 API 与服务
└── cli.py             # 命令行入口
src/doomsday_seed/web/  # 纯静态前端（离线自足）
data/                  # 种子库与数据库（不入库，永不外传）
tests/                 # 流水线、恢复、API 与核心测试
docs/                  # 开发文档与研究记录
```
