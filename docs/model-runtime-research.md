# 本地模型运行时调研

核对日期为 2026-11-10。以下是 llama.cpp 文本对话和单图理解之外的候选方案。上游文档验证了调用方式，目标 Windows 机器的安装、质量和性能仍需实测。

## OCR 与语音

- **OCR 用 PaddleOCR 3.x + PP-OCRv5 mobile，先走 CPU。** 下载检测和识别的推理模型 `PP-OCRv5_mobile_det`、`PP-OCRv5_mobile_rec`，分别传入 `text_detection_model_dir` 和 `text_recognition_model_dir`。首版只接收方向正常、平整的本地图片，关闭 `use_doc_orientation_classify`、`use_doc_unwarping`、`use_textline_orientation`。启用任一项时将对应模型加入种子包。OCR 输出保留 `rec_texts`、`rec_polys`、`rec_scores`，方便用户核对原图。PaddleX `release/3.7` 用 `PADDLE_PDX_DISABLE_MODEL_SOURCE_CHECK=True` 跳过模型站点连通性探测，实际接入时按锁定版本核对并跑禁网测试。[PaddleOCR 通用 OCR](https://www.paddleocr.ai/main/en/version3.x/pipeline_usage/OCR.html) · [PaddlePaddle 安装](https://www.paddleocr.ai/main/en/version3.x/paddlepaddle_installation.html) · [PaddleX 探测源码](https://github.com/PaddlePaddle/PaddleX/blob/release/3.7/paddlex/inference/utils/official_models.py)
- **语音转写用 whisper.cpp。** `whisper-cli` 加载本地 `ggml-base.bin`，用 `-l zh` 跑中文基线。带 `.en` 的权重面向英语。首版统一输入为 16 kHz、单声道、16-bit PCM WAV，接收其他格式时随包提供 FFmpeg 转码工具。输出文本和分段时间戳。启用 VAD 时另带 VAD 权重。[whisper.cpp 快速开始与 VAD](https://github.com/ggml-org/whisper.cpp#quick-start) · [官方转换权重清单](https://github.com/ggml-org/whisper.cpp/tree/master/models)
- **文字朗读用 Piper。** 用本地 `.onnx` 和同名 `.onnx.json` 加载音色，先输出 WAV。简体中文可用 `zh_CN-huayan-medium` 验证发音。Piper 引擎是 GPL-3.0，音色逐个核查 `MODEL_CARD`。Huayan 的卡片将训练集许可标为 `Unknown`，将该音色加入可分发种子包前先核清来源。[Piper 引擎](https://github.com/OHF-Voice/piper1-gpl) · [本地 Python API](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/API_PYTHON.md) · [音色文件说明](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/VOICES.md) · [Huayan 音色卡](https://huggingface.co/rhasspy/piper-voices/blob/main/zh/zh_CN/huayan/medium/MODEL_CARD)

## 图片与视频

- **文生图用 Diffusers + SDXL Base。** 从固定修订打包一套可加载的 Diffusers 目录，以 `model_index.json` 列出的组件为准，包括权重、配置、分词器、文本编码器、调度器和 VAE。用 `from_pretrained(本地目录, local_files_only=True)` 加载，只保留与所选精度匹配的权重文件。单文件导入仍需配套的本地配置，首版以完整目录为交付格式。首个验收目标是固定提示词、种子、尺寸和步数生成可解码 PNG。SDXL Base 的模型卡标明 CreativeML Open RAIL++-M 许可。[Diffusers 本地加载](https://huggingface.co/docs/diffusers/using-diffusers/loading) · [单文件导入](https://huggingface.co/docs/diffusers/using-diffusers/other-formats) · [SDXL 模型卡](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0) · [组件索引](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0/blob/main/model_index.json)
- **视频理解先复用图片推理。** 用本地 FFmpeg 按固定频率采样，记录帧对应的时间，按时间顺序分析关键帧，产品能力标为「视频抽帧理解」。需要模型直接接收视频输入时，再验证 Apache-2.0 的 `Qwen/Qwen3-VL-2B-Instruct` + Transformers，随包提供完整权重、处理器和分词器配置，并限制片长、采样帧数和输入分辨率。采用 TorchCodec 解码时锁定与 PyTorch 匹配的版本，Windows 同时准备包含共享库的 FFmpeg。需要理解对白时，提取音轨并调用独立 ASR。[FFmpeg 滤镜](https://ffmpeg.org/ffmpeg-filters.html) · [Qwen3-VL-2B 模型卡](https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct) · [Transformers 视频处理器](https://huggingface.co/docs/transformers/video_processors) · [TorchCodec 安装](https://github.com/meta-pytorch/torchcodec#installing-torchcodec)
- **文生视频用 Diffusers + Wan2.1 T2V 1.3B 做独立 CUDA 实验。** 使用 `Wan-AI/Wan2.1-T2V-1.3B-Diffusers` 的本地组件目录，固定 832 × 480、帧数和步数，随包准备 `imageio`、`imageio-ffmpeg` 以导出 MP4。Diffusers v0.33.1 的 CPU offload 示例标注 11 GB 显存，仅作为该示例的参考。按目标机实测峰值显存、内存和端到端用时，再决定是否接入。官方原生脚本提供 DashScope 提示词扩写，离线方案保持关闭。[Wan 1.3B 模型卡](https://huggingface.co/Wan-AI/Wan2.1-T2V-1.3B-Diffusers) · [Diffusers 1.3B 示例](https://huggingface.co/docs/diffusers/v0.33.1/api/pipelines/wan) · [视频导出源码](https://github.com/huggingface/diffusers/blob/main/src/diffusers/utils/export_utils.py)

## 离线种子与验收

1. **联网准备。** 锁定模型修订、运行时和后端版本、目标 OS、CPU 架构及 Python ABI。模型文件和依赖按原有目录打包，清单记录来源、许可证、大小和 SHA-256。Python 运行时备齐该目标平台的 wheel 及传递依赖，另带所需解码器、原生库和固定样例。用 `pip download` 准备 wheelhouse，使用 `pip install --no-index --find-links ...` 安装。[Hub 下载目录与修订](https://huggingface.co/docs/huggingface_hub/guides/download) · [pip 下载与离线安装](https://pip.pypa.io/en/stable/cli/pip_download/)
2. **隔离验收。** 在目标 OS 的新环境中清空用户模型缓存，切断网络，解包后从本地安装，再冷启动。所有媒体和模型输入传本地路径。HF 运行时启动前设 `HF_HUB_OFFLINE=1`，加载时使用 `local_files_only=True`。这些开关约束 Hugging Face Hub 访问，整条链路用系统层断网验证。若验收要求零外联尝试，另记录进程及子进程的网络事件。删除一个必需文件再测一次，预期返回可定位的缺件错误。[HF Hub 离线变量](https://huggingface.co/docs/huggingface_hub/package_reference/environment_variables#hf_hub_offline) · [Diffusers 本地加载参数](https://huggingface.co/docs/diffusers/api/pipelines/overview)
3. **记录能力与代价。** 每个样例记录硬件、版本、冷启动时间、推理时间、峰值 RAM/VRAM 和结果文件。OCR 用带标注的中英图片算字符错误率（CER），并检查框位置。ASR 用中文 CER、英文词错误率（WER）和实时系数（处理秒数除以音频秒数），检查时间戳。TTS 核验 WAV、中文可懂度和数字发音。文生图检查尺寸、解码和提示词匹配。视频理解用可定位事件和先后顺序问答，文生视频检查 MP4 可播放、时长、帧率和跨帧一致性。质量阈值在锁定样本和目标机后制定。
